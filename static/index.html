连接你的 App

    
    
      
  1. HTTP 代理
    将客户端代理设置为 127.0.0.1:8088。真机需通过 --listen-host 0.0.0.0 启动，并使用 Mac 的局域网 IP。
    2. 
      
  2. HTTPS 证书
    客户端经代理打开 http://mitm.it 安装本工具的 CA，并在系统中信任。iOS 需在「设置 → 通用 → 关于本机 → 证书信任设置」开启信任。
    3. 
      
  3. 录制 / 回放
    开启录制后正常操作 App。选用历史或 JSON，再切换回放；命中的方法、协议、域名、端口和路径使用本地响应，其余请求正常转发。
    4. 
    

    
无需嵌入 SDK。不会自动修改系统代理或证书信任。证书锁定、自定义直连连接以及 HTTP/3 流量需要客户端额外配置。
